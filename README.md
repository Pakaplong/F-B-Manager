# เว็บแอปพลิเคชันบริหารจัดการธุรกิจ F&B (เครื่องดื่มและเบเกอรี่) สำหรับครอบครัว
**แนวคิดการออกแบบ:** Mobile & iPad First | ภาษาไทย 100% | Clean Minimal Theme | ฐานข้อมูล Google Sheets

---

## 🚀 วิธีเปิดใช้งาน GitHub Pages เพื่อใช้บน iPad / มือถือ
1. ไปที่เมนู **Settings** ในหน้า GitHub Repository ของคุณ
2. เลื่อนลงไปที่แถบเมนูด้านซ้าย เลือก **Pages**
3. ตรงส่วน **Branch** ให้เลือก `main` (หรือ `master`) และโฟลเดอร์เป็น `/ (root)` แล้วกด **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น `https://<your-username>.github.io/<repo-name>/`
5. ส่งลิงก์นี้ให้ทุกคนในครอบครัวเปิดผ่าน Safari / Chrome บนมือถือหรือ iPad ได้ทันที!

## 📁 ไฟล์สำคัญในโปรเจกต์
- `index.html` : หน้าบ้านของระบบ (Frontend SPA) มีทั้ง POS, คลังสต็อก, จัดสูตร R&D, สรุปยอดขาย
- `Code.gs` : โค้ดหลังบ้าน (Backend REST API) สำหรับนำไปวางใน Google Apps Script เพื่อเชื่อมต่อ Google Sheets
- `IMPLEMENTATION.md` : เอกสารอธิบายโครงสร้างฐานข้อมูลและฟังก์ชันการทำงานอย่างละเอียด
